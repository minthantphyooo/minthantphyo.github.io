Personal portfolio website for Min Thant Phyo, MSc Computing graduate.

## GitHub Pages
1. Create a repository named `mewyyuu.github.io`.
2. Upload these files.
3. Add your CV as `MIN-THANT-PHYO-CV.pdf`.
4. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. Your site will be at `https://mewyyuu.github.io/`.
